# Ollama

Status: Operational
Host: [dev-workstation](../dev-workstation/)
Models: [models.md](models.md)

Local LLM inference. Provides an OpenAI-compatible API for self-hosted models, accelerated by the host's NVIDIA RTX 3060 (12 GB VRAM). Started on demand rather than always-on — invoked when an LLM workload is needed at the desk.
