# Network

Status: Operational

The home network — internet, modem, gateway, switches, Wi-Fi, and structured wiring. A UniFi managed network built around a UDM-SE and three Wi-Fi 7 APs in a basement crawl-space rack, with VLAN segmentation (Core / Clients / IoT, a repurposed-Default Management network, and a deferred Guest tier). It replaced the 1st-gen Google Wifi mesh, now retired.
