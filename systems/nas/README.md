# NAS

Status: Planned

Network-attached storage for the home lab — bulk file storage, backup target, and a self-hosted "personal cloud" for browsing photos and home videos (Synology Photos / Drive). Planned as a Synology DiskStation **DS925+** (4-bay desktop) set on top of the crawl-space rack. Initial fill is 3 × 8 TB in SHR-1 (~16 TB usable) with one bay left open for later expansion.
